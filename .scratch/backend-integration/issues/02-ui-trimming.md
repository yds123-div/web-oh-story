# 02 — 界面裁剪：隐藏无后端支撑的功能

**Parent spec:** `spec.md`（同目录）

**What to build:** 界面上"可见即真实可用"。移除所有没有后端接口支撑的功能入口与展示：模板列表、通知中心、积分、存储用量、创作页的小说模式入口；创意对话页隐藏或降级。纯浏览型静态页面（画布管理、资产广场、空间页）保留现有静态内容不真实化，保证主线联调期间导航结构完整。

**Blocked by:** None — can start immediately

**Status**: done

- [x] 首页与创作页的模板列表区隐藏（后端无 templates 接口），不再调用对应 API 函数
- [x] 通知中心（铃铛及面板）隐藏（后端无 notifications 接口）
- [x] 顶栏积分展示隐藏（后端无 credits 接口），相关调用移除
- [x] 存储用量类展示隐藏（后端无对应接口）
- [x] 创作页"小说模式"入口隐藏，只保留剧本模式（后端小说链路二期接）
- [x] 创意对话页隐藏或降级为占位（Socket.io Agent / 图片编辑工作流二期接），路由与导航不再直接可达误导用户
- [x] 画布管理、节点画布、资产广场、空间页保留现有静态内容，仅确保它们不再触发对不存在后端接口的调用
- [x] 被隐藏功能对应的 API 函数从页面调用处移除（函数本身可保留供测试或二期）
- [x] 界面上不再出现因缺少后端接口导致的报错或静默失败
